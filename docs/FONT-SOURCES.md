# Fonts

The interface uses Noto Sans KR for Korean text and decimal digits, Arial for Latin body text, and Arial Black for Latin display text when installed. Browser fallback fonts remain listed for platforms without Arial.

Noto Sans KR Variable is self-hosted from `@fontsource-variable/noto-sans-kr` version 5.3.1. Its Unicode subsets are downloaded and SHA-256 verified through `assets.manifest.json`. The original font is distributed under SIL Open Font License 1.1. The license is available at `/assets/noto-sans-kr-LICENSE.txt` and is restored by the asset download script.
